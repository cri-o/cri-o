## Changelog since v1.35.11

### Changes by Kind

#### Dependency-Change
 - CRI-O's minimum Go version and static-build compiler are now Go 1.26.10. (#10493, @bitoku)

#### Bug or Regression
 - Fixed a deadlock where CRI-O ignored SIGTERM when in-flight RPCs were blocked waiting for CNI readiness during node shutdown. The CNI manager is now shut down before the gRPC server stops, and a forced stop is scheduled as a fallback after 30 seconds. (#10545, @nispriha)
 - Fixed a possible CRI-O crash when stopping containers with active exec processes. (#10529, @openshift-cherrypick-robot)

#### Uncategorized
 - Fix SELinux labeling so systemd/init containers receive container_init_t again instead of remaining container_t and failing to create cgroups. (#10509, @aksjadha)
