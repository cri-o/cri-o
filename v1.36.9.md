## Changelog since v1.36.8

### Changes by Kind

#### Dependency-Change
 - CRI-O's minimum Go version and static-build compiler are now Go 1.26.10. (#10492, @bitoku)

#### Bug or Regression
 - Fixed a deadlock where CRI-O ignored SIGTERM when in-flight RPCs were blocked waiting for CNI readiness during node shutdown. The CNI manager is now shut down before the gRPC server stops, and a forced stop is scheduled as a fallback after 30 seconds. (#10516, @openshift-cherrypick-robot)
