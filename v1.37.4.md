## Changelog since v1.37.3

### Changes by Kind

#### Dependency-Change
 - Bumped Go to 1.27.2 and golang.org/x/net to v0.60.0, fixing CVE-2026-78669,
  CVE-2026-78667, and CVE-2026-97031 (#10503, @amritansh1502)

#### Bug or Regression
 - Fixed a deadlock where CRI-O ignored SIGTERM when in-flight RPCs were blocked waiting for CNI readiness during node shutdown. The CNI manager is now shut down before the gRPC server stops, and a forced stop is scheduled as a fallback after 30 seconds. (#10473, @openshift-cherrypick-robot)
 - Fixed pods with a RuntimeClass and a dropped infra container running on the default runtime handler.
  Fixed creating infra and Guaranteed pod containers when CRI-O runs in a user namespace. (#10523, @openshift-cherrypick-robot)
