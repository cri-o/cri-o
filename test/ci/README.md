# Change based test selection

The files in this directory support the change based test selection (test
impact analysis) described in [`scripts/ci.md`](../../scripts/ci.md).

- `bats-coverage-map.json` maps every bats file below `test/` to the Go
  packages which were executed while running it. It is regenerated by the
  `bats-coverage-map` GitHub Actions workflow and consumed by
  `hack/ci/select-bats.sh`. Until the first generated map is merged the
  integration suite always runs in full.
